# Acoustic Kit

One hit per drum from **Virtuosity Drums**, a sampled jazz/club drum kit played
by Austin McMahon at Virtuosity Musical Instruments, Boston, with auxiliary
percussion from VSCO 2. Released under CC0 1.0 (see LICENSE-CC0.txt):
https://github.com/sfzinstruments/virtuosity_drums

Made by `scripts/make-acoustic-kit.mjs` (trimmed, faded, levelled, 16-bit WAV).
